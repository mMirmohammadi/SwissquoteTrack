# Stable protocol interface — @sq/protocol

Consumers import from `@sq/protocol` (source entry `src/index.ts`). All bigint values in HTTP and copy-paste codes are decimal strings; in signing/helpers they are bigint. No secrets are sent to services.

## Frozen exports

- Types: `WalletSetup {owner, cardGuardian, partnerGuardian, sqGuardian: Address; saltNonce: bigint; chainId?: number}`, `SafeTx {to: Address; value: bigint; data: Hex; operation: 0|1; safeTxGas, baseGas, gasPrice: bigint; gasToken, refundReceiver: Address; nonce: bigint}`, `RecoveryRequest {wallet, module, newOwner: Address; nonce: bigint; chainId: number}`, `GuardianApproval {signer: Address; signature: Hex}`.
- Constants: `ADDRESSES`, `MODULES`, `CHAIN_ID`, `LOCAL_CHAIN_ID`, `DERIVATION_PATH`, `GUARD_STORAGE_SLOT`, `FALLBACK_STORAGE_SLOT`, `MODULE_CODE_HASHES`, `ZERO_ADDRESS`, `SENTINEL_ADDRESS`, `USDC_LIMIT`, `ETH_LIMIT`, `PUBLIC_RPC_URLS`, `HISTORY_RPC_URLS`, `SEPOLIA_HISTORY_START`, `LOG_CHUNK_BLOCKS`. Sepolia RPCs: `PUBLIC_RPC_URLS` = publicnode (sends and current reads; serves only recent logs) followed by the two `HISTORY_RPC_URLS` (tenderly, ethpandaops; full log history). Read wallet history through `HISTORY_RPC_URLS`.
- ABIs: `safeAbi`, `factoryAbi`, `moduleAbi`, `multiSendAbi`, `moduleSetupAbi`, `erc20Abi`, `fallbackHandlerAbi`.
- `buildWalletInitializer(setup: WalletSetup): Hex`; `computeWalletAddress(setup: WalletSetup, proxyCreationCode: Hex): Address`; `buildDeployCall(setup: WalletSetup): {address: Address; abi: typeof factoryAbi; functionName: 'createProxyWithNonce'; args: readonly [Address, Hex, bigint]}`.
- `encodeMultiSend(calls: readonly MultiSendCall[]): Hex`; `decodeMultiSend(data: Hex): MultiSendCall[]`; `buildCancelRecoveryTx(wallet: Address, nonce: bigint, pendingModules: readonly Address[]): SafeTx`; `buildRotateOwnerTx(wallet: Address, oldOwner: Address, newOwner: Address, nonce: bigint): SafeTx`; `makeSafeTx(input: Pick<SafeTx,'to'> & Partial<SafeTx>): SafeTx`.
- `safeTxTypedData(wallet: Address, tx: SafeTx, chainId?: number)`; `hashSafeTx(wallet: Address, tx: SafeTx, chainId?: number): Hex`; `signSafeTx(privateKey: Hex, wallet: Address, tx: SafeTx, chainId?: number): Promise<Hex>`; `encodeExecTransaction(tx: SafeTx, signatures: Hex): Hex`.
- `recoveryTypedData(request: RecoveryRequest)`; `hashRecovery(request: RecoveryRequest): Hex`; `signRecovery(privateKey: Hex, request: RecoveryRequest): Promise<GuardianApproval>`; `sortApprovals(approvals: readonly GuardianApproval[]): GuardianApproval[]`; `assertRecoveryHash(client: PublicClient, request: RecoveryRequest): Promise<void>`; `encodeRecoveryCall(request: RecoveryRequest, approvals: readonly GuardianApproval[]): Hex`.
- `ownershipProofText(clientId: string, wallet: Address, nonce: string): string`; `safeMessageTypedData(wallet: Address, messageHash: Hex, chainId?: number)`; `signOwnershipProof(privateKey: Hex, clientId: string, wallet: Address, nonce: string, chainId?: number): Promise<{message: string; hash: Hex; signature: Hex}>`; `verifyOwnershipProof(client: PublicClient, wallet: Address, hash: Hex, signature: Hex): Promise<boolean>`.
- `encodeCode(code: SetupCode | RequestCode | ApprovalCode): string`; `decodeCode(value: string): SetupCode | RequestCode | ApprovalCode`; `decodeSetupCode`, `decodeRequestCode`, `decodeApprovalCode`: `(value: string) => matching type`. Codes use `{v:1, chainId, kind:'setup'|'request'|'approval', ...}`. Setup includes wallet, owner, partnerGuardian, sqGuardian, saltNonce; request includes wallet, module, newOwner, nonce; approval includes signer, signature. Card address is deliberately absent from setup code.
- `classifyTransaction(wallet: Address, tx: SafeTx): TransactionClassification` with `{class:'Protective'|'Admin'|'Large'|'Small'; requiresPasskey:boolean; relayAllowed:boolean; reason:string; recipients:Address[]}`. Forbidden delegatecalls and nonzero refund/gas fields are never relayed; decoded batches inherit strictest class. Unknown tokens/calldata are conservatively Large rather than assuming harmless calls. Classifier does not replace session ownership, Settings-origin, passkey validation, sanctions checks or transaction simulation in the relayer.
- `generateOwnerSeed(): string`; `generateCardSeed(): string`; `mnemonicToPrivateKey(mnemonic: string): Hex`; `mnemonicToAddress(mnemonic: string): Address`; `ownerFingerprint(owner: Address): string`; `randomSaltNonce(): bigint`.
- `encryptSeed(mnemonic: string, passphrase: string): Promise<EncryptedSeed>`; `decryptSeed(envelope: EncryptedSeed, passphrase: string): Promise<string>`; `generateKitCode(): Promise<string>`; `validateKitCode(code: string): Promise<boolean>`; `createKit(mnemonic: string, code: string, metadata: KitMetadata): Promise<EmergencyKit>`; `openKit(kit: EmergencyKit, code: string): Promise<{mnemonic:string; owner:Address}>`. PBKDF2-SHA256 600000, AES-256-GCM, scure BIP39/BIP32. Kit code is 32 base32 entropy characters plus checksum (displayed separately with hyphens).
- Exported `VerificationOptions {fromBlock?:bigint; expectedWallet?:Address; expectedCurrentOwner?:Address}`; `verifyWallet(client: PublicClient, setup: WalletSetup, options?: VerificationOptions): Promise<WalletVerification>`; `verifyWalletIndependent(clients: readonly PublicClient[], setup: WalletSetup, options?: VerificationOptions): Promise<WalletVerification>`. Independent verification requires two independent clients. Both verifiers reject hidden owners/modules/guard, pin module code, check pending requests and current guardians/thresholds, require complete owner multisig history when nonce > 0, and scan module execution history regardless of Safe nonce. Returns `{ok:boolean; wallet:Address; reasons:string[]; nonce?:bigint}`. Verification fails closed on missing history/RPC failures; options.fromBlock must cover wallet creation. `historyStartBlock(chainId: number, head: bigint): bigint` is the default start: `SEPOLIA_HISTORY_START` on chain 11155111 once the head has reached it, otherwise 0; an explicit `fromBlock` wins. History is read with `eth_getLogs` in ranges of at most `LOG_CHUNK_BLOCKS` (10,000) blocks up to one pinned head block; any failed range fails verification. `setup.owner` always remains the original CREATE2 creation owner. Current owners must exactly match `[options.expectedCurrentOwner ?? setup.owner]` with threshold 1. Consumers must explicitly authenticate a replacement owner before supplying this option; never fill it from RPC `getOwners` alone. Malformed, zero, sentinel and wallet-self expected owners fail closed. The default still rejects unacknowledged owner replacement.
- HTTP interfaces exported from `src/api.ts`; decimal string SafeTx wire helper `safeTxToWire`, `safeTxFromWire`. Wire input requires canonical string uint256 values for value/nonce/safeTxGas/baseGas/gasPrice, valid target/gasToken/refundReceiver addresses, byte-aligned hex calldata and operation 0 or 1. Request codes reject zero wallet and zero/sentinel replacement owner. `openKit` converts AES authentication failures into `Unable to decrypt kit: incorrect code or damaged kit`, without exposing the supplied code, mnemonic or raw WebCrypto details.

## Integration

Package scripts: build/typecheck/test. Each service should accept runtime chain 31337 or 11155111 explicitly; default signatures use Sepolia. Source modules below entry may be imported only for debugging; consumers should use entry exports. No install or root config changes by this lane.
