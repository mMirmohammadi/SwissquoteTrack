## Exact service contract

Use the existing browser rather than a direct handcrafted submission when browser execution evidence is the goal. The browser reads the current Safe nonce, builds canonical calls, obtains the service preview, requires explicit risk acknowledgement, rechecks nonce, and asks the shell to sign and relay. Sources: [DeFi feature:49–110](</home/dev/Hackaton/SwissquoteTrack/.worktrees/v3/swissquote-wallet/apps/wallet/src/features/dapps/index.tsx#L49-L110>), [wallet shell:217–249](</home/dev/Hackaton/SwissquoteTrack/.worktrees/v3/swissquote-wallet/apps/wallet/src/App.tsx#L217-L249>).

Preview: `POST /dapps/preview`, authenticated `Bearer` session, JSON body `{ wallet, tx, dappId: 'compound' }`. `tx` is the Safe wire transaction: `to`, `value`, `data`, `operation`, `safeTxGas`, `baseGas`, `gasPrice`, `gasToken`, `refundReceiver`, `nonce`. Integer fields are unsigned decimal strings; `operation` is numeric. Safe gas/refund fields must be zero and gasToken/refundReceiver zero addresses. This endpoint requires KYC and the wallet linked/verified for this user, screens the calls and registry addresses, and returns `summary`, `effectsHash`, `blockNumber`, `dappId`, `warnings`. Source: [app.ts:119–125](</home/dev/Hackaton/SwissquoteTrack/.worktrees/v3/swissquote-wallet/services/swissquote/src/app.ts#L119-L125>), [policy.ts:10–13](</home/dev/Hackaton/SwissquoteTrack/.worktrees/v3/swissquote-wallet/services/swissquote/src/policy.ts#L10-L13>).

Submission: `POST /relay/safe-tx`, same session, JSON body `{ wallet, tx, signature, source: 'dapp', dappId: 'compound', effectsHash, chainId: 11155111 }`. The service demands the fresh Safe nonce and exactly one valid EIP-712 signature from the sole current owner (threshold 1). It revalidates simulation effects immediately before sending. Sources: [app.ts:161–194](</home/dev/Hackaton/SwissquoteTrack/.worktrees/v3/swissquote-wallet/services/swissquote/src/app.ts#L161-L194>), [chain.ts:67–75](</home/dev/Hackaton/SwissquoteTrack/.worktrees/v3/swissquote-wallet/services/swissquote/src/chain.ts#L67-L75>).
