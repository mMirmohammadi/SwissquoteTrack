# Domain documents

Use a single project glossary in `CONTEXT.md`; avoid implementation details there.
Create it lazily after the first agreed term. Decision records belong in
`Docs/adr/` and should be created only for meaningful trade-offs.
Templates: [glossary](../../.agents/skills/domain-modeling/CONTEXT-FORMAT.md)
and [ADR](../../.agents/skills/domain-modeling/ADR-FORMAT.md).
An absent glossary or ADR directory is normal at project start.
