## Components and trust boundaries

| Component | Role and public data flow | Real versus MOCK / proof limit |
| --- | --- | --- |
| Client wallet browser | Generates/encrypts owner key locally; signs wallet proof and exact spend; sends public context/signatures | Real browser implementation. Login/passkey sponsorship is not an on-chain co-owner; malicious publisher can expose an unlocked key |
| Separate Recovery Desk | Emits public card approval for wallet copy; encrypted kit opening, key export and optional RPC owner/card check | Real separate page; secrets stay local by design. Desk itself does **not broadcast the recorded sweep**. Publisher/governance independence is **not yet verified**; reproducibility remains unproved |
| Swissquote service | Auth, proof verification, screening, preview/recheck, budgets and relayer; module-B helper | Real service execution for the bounded payment/supply. Bank/KYC/mailbox/demo list/software guardian vault are MOCK |
| Separate partner service | Signs module A after its check; separate process/storage | Face check and unencrypted SQLite guardian-key protection are MOCK; separate storage is not independent governance or HSM assurance |
| Live screening adapters | Public RedStone OFAC/EU/UN-derived oracle and USDC blacklist reads | Clear results recorded in payment/supply. Demo hits are MOCK; secondary source limited; no comprehensive Swiss sanctions/legal approval |
| Public Sepolia Safe 1.4.1 | One owner signs; EIP-1271 verifies control; two enabled recovery modules | Real contracts, test funds. Control proof is not beneficial ownership or bank acceptance |
| Candide module A | Card + partner, 180-second demo delay; owner can cancel | G1 public-browser start/finalize and new-owner payment completed across retained sessions; public cancellation remains older SCRIPTED evidence |
| Candide module B | Card + Swissquote, 259,200-second delay; owner can cancel | Public script started then cancelled; full three-day public completion absent |
| USDC and Compound III test deployment | One exact approve → supply → approve-zero batch | One mined public browser/service 1-USDC supply on a second wallet; **third-party test deployment**, not official market, withdrawal/swap or investment endorsement |
| RPC-only kit-exit script | Current kit key signs, independent FUNDER submits/pays gas | Public SCRIPTED 3-USDC sweep without helper calls. Not a service-shutdown drill, saved-file browser broadcast, all-token exit or offline settlement |

The [initializer](<../../swissquote-wallet/packages/protocol/src/wallet.ts#L37-L44>) sets card+partner A and card+Swissquote B; never both helpers on one recovery lock. Owner signatures can change rules and bypass off-chain fee/passkey policy if independently funded. The [Desk implementation](<../../swissquote-wallet/apps/recovery-tool/src/main.ts#L49-L107>), [service relay](<../../swissquote-wallet/services/swissquote/src/chain.ts#L147-L158>), [screening](<../../swissquote-wallet/services/swissquote/src/screening.ts#L36-L59>) and [kit script](<../../swissquote-wallet/scripts/kit-sweep.ts#L7-L26>) anchor the diagram's source badges.

The assisted recovery network path is explicit: the [Desk](<../../swissquote-wallet/apps/recovery-tool/src/main.ts#L75-L84>) emits a public approval code for the user to copy into the wallet; it sends no helper or relay transaction. The [wallet](<../../swissquote-wallet/apps/wallet/src/features/recovery/index.tsx#L75-L84>) calls the selected helper with public request fields and MOCK identity input, receives its public approval, then sends card + helper signatures to Swissquote `/relay/recovery`. The [partner](<../../swissquote-wallet/services/partner/src/service.ts#L87-L93>) returns approval, not a module submission. The [Swissquote relay](<../../swissquote-wallet/services/swissquote/src/app.ts#L272-L277>) submits through the [chain adapter](<../../swissquote-wallet/services/swissquote/src/chain.ts#L63-L69>) to the selected recovery module. For B, Swissquote is both helper and relay; the locks remain separate. Card/owner words and kit codes do not go to helpers.
